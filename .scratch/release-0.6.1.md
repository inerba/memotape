This release brings automatic updates, asks for your recording choices before every recording and lets you copy live text while it is still arriving.

## New

- **Automatic updates**
  When a new version is available, the notice at the bottom of the sidebar now offers Download and install. One click downloads the update, with its progress in the notice, checks that it really comes from Memotape and installs it: Memotape closes and opens again on the new version. While a recording, a transcription or speaker recognition is running, the button waits for it to finish, and your unsaved notes are saved or kept before installing. What's new opens the release page. If the download fails, the notice offers Try again and Download manually.

## Improvements

- **Recording options before every recording**
  New recording now always opens a dialog with your choices before it starts: Microphone and System audio, each with its device, noise filter, sensitivity and Recognize speakers, and Transcribe live. The dialog opens from every place you can start a recording: the sidebar button, the collapsed sidebar, Ctrl+N and the Home page. Record has the focus, so Ctrl+N then Enter starts recording right away. The ▾ arrow next to the button is gone. Your choices are saved as soon as you make them, also if you press Cancel.

- **Transcription model and speech language for live transcription**
  Below Transcribe live, the recording dialog now shows the transcription model and the speech language. These are the same choices used by Transcribe and in Settings, so changing them in one place changes them everywhere. They are available only while Transcribe live is on.

- **Copy part of the live text**
  While you record, you can select and copy any part of a sentence as soon as it is transcribed, without waiting for the speaker's turn to end or for the recording to stop. The selection stays in place while new sentences arrive. The text still being recognized, shown in italics, cannot be selected.

## Note

Automatic updates start with this version: if you have Memotape 0.6.0 or earlier, download and install 0.6.1 from the assets below one last time.
